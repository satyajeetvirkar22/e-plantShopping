# Paradise Nursery Shopping Application

Welcome to the Paradise Nursery Shopping Application! This is an e-commerce web application for browsing and purchasing plants online.

## Features
- Landing page with company details and Get Started button
- Catalog of plants divided into categories (Air Purifying Plants, Aromatic Fragrant Plants, Insect Repellent Plants, Medicinal Plants, Low Maintenance Plants)
- Add to cart functionality with dynamic item count badge
- Shopping cart with total price calculation, increment, decrement, and item removal
- Responsive navigation across Home, Plants, and Cart
